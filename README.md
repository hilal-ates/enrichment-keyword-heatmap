# Enrichment Keyword Counter & Heatmap

Counts enrichment keywords/categories and generates a heatmap visualization across samples/groups.

## Overview
- **input:** Enrichment results table (e.g., CSV/TSV with pathways/terms and counts or scores).
- **script:** Filters enrichment terms, counts matching keywords and formats data for plotting.
- **output:** Heatmap visualization comparing keyword counts across patients.
